## 🎮 HOW TO USE

### **Quick Start:**
1. **Double-click any desktop shortcut** (they're in `~/FileCleanupTools/`)
2. **Choose scan type:**
   - Option 1: Quick Scan (Downloads, Desktop, etc.)
   - Option 2: Full System Scan
   - Option 3: Custom Directory Scan
   - Option 4: Cleanup Old & Large Files
3. **View results:** Option 5 opens HTML report in browser
4. **Exit cleanly:** Option 7 closes terminal completely

### **What Each Scan Does:**
- **Finds large files** (>100MB) taking up disk space
- **Identifies old files** (>1 year) potentially outdated
- **Detects unused files** (>6 months since last access)
- **Finds duplicates** wasting storage
- **Calculates risk scores** for cleanup prioritization
